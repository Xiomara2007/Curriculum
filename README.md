# Portafolio educativo de Xiomara Lucas

Este proyecto es un portafolio web personal para presentar la trayectoria, perfil y vocación de Xiomara Lucas como estudiante de Educación Inicial. La página está diseñada con un estilo cálido, moderno y cercano, pensado para reflejar creatividad, ternura y aprendizaje en la primera infancia.

## Descripción

La web incluye secciones como:

- presentación personal
- perfil profesional y académico
- formación y experiencia
- habilidades y aptitudes
- galería visual
- contacto

Además, cuenta con una pantalla de bienvenida interactiva y la posibilidad de personalizar imágenes desde el navegador, guardándolas localmente mediante IndexedDB.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript vanilla
- Google Fonts
- IndexedDB para almacenamiento local de imágenes

## Estructura del proyecto

```text
Curriculum/
```

## Requisitos

Solo necesitas un navegador moderno para visualizar el sitio.

## Cómo ejecutar

1. Descarga o clona este proyecto.
2. Abre la carpeta `Curriculum`.
3. Ejecuta `index.html` directamente en tu navegador.

También puedes usar un servidor local simple, por ejemplo:

```bash
python -m http.server 8000
```

Luego accede a:

```text
http://localhost:8000
```

## Funcionalidades destacadas

- diseño totalmente responsive
- navegación con menú móvil
- animaciones de entrada y scroll
- galería visual con detalles interactivos
- edición local de imágenes sin subir archivos a internet
- experiencia visual enfocada en un perfil educativo y humano

Este sitio está pensado como una presentación digital personal y académica, por lo que su contenido está orientado a mostrar la identidad, trayectoria y vocación docente de la autora.
